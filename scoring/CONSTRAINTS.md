# Scientist Constraints

## Data
Use only fold datasets generated by `data/synthetic_smartposer.py` with fixed seed 7 for the benchmark scores. Do not train on each fold's held-out synthetic subject, and do not replace the test splits with easier generated data.

## Model Scale
The parameter count must be reported in each method's `metadata.json` and scored as `param_count_k`. Improvements should stay in the same small-model regime as the paper; increasing the model by more than 2x over SmartPoser's 46.4k reported parameters violates the constraint.

## Inputs
Use only the provided sensor feature streams: raw phone-watch distance, phone/watch orientations, and phone/watch accelerations. Do not add ground-truth joint coordinates, future labels, or external pose measurements as model inputs.

## Compliance Checklist
- [ ] Training uses only each fold's generated training windows.
- [ ] Evaluation uses the fixed generated test windows for all 10 folds.
- [ ] Model parameter count is reported and is not more than 92.8k.
- [ ] Inputs are limited to the provided sensor features.
